The Weight and Balance program itself is what must run.
to add your own instructors and planes you use, edit the files and add /n in between items.
The order for the instructorinfo.txt file is "instructor name" /n "instructor weight" with no spaces, and name as you wish to type it into the program later.
The order for planeinfo.txt is "Tail number" /n "Empty weight" /n "Empty arm" /n "Empty moment" /n "Aircraft type" tail numbers should include country designation letters.
Both of these files can be infinite in size, and the program will work.
If you wish to make this an application on your desktop, just make a shortcut to the python file and as long as its opening with python 3.12 (have python installed)

Ai has not and will not be used in this program
